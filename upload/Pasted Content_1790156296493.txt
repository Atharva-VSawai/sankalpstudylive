10. LIVEKIT TOKEN ENDPOINT
=====================================================

Create a server endpoint following the existing API conventions.

For example:

POST /api/rooms/[roomId]/token

Request:

{
  "roomId": "gate-focus-room"
}

or use the existing route parameter structure.

The endpoint MUST:

1. Authenticate the user.
2. Load the Sankalp room.
3. Verify the room exists.
4. Verify the room is public/official.
5. Verify the user is allowed to enter.
6. Check the 60-minute free allowance.
7. Check active paid entitlement.
8. Determine the exact LiveKit room name server-side.
9. Generate a LiveKit AccessToken server-side.
10. Set a short expiration.
11. Scope the token to exactly that room.
12. Return only safe client data.

Example response:

{
  "serverUrl": "wss://your-project.livekit.cloud",
  "token": "<short-lived-token>",
  "roomName": "gate-focus-room"
}

NEVER return:

LIVEKIT_API_SECRET

unless an actual server-side administrative workflow requires them.
